Privacy Policy

Claude Gmail · Last updated: October 2026 · Home

Who this is for

Claude Gmail is a private tool built and used by a single person, Jayden Leung (the “owner”). It is not offered to the public. The only people whose data it can ever touch are the owner and, through the owner’s own accounts, the people who email him.

What it accesses

Using Google’s Gmail and Calendar APIs, and only for the owner’s own Google accounts, it can access:

  • Email messages, threads, labels and drafts (including the ability to send, label, archive and trash mail when the owner approves).
  • Google Calendar events and calendars.
  • The email address of each connected account, to make sure it is acting as the right one.

How it is used

Only to carry out tasks the owner asks for or schedules: summarizing and searching mail, drafting and organizing messages, summarizing newsletters and job alerts, and managing the owner’s calendar. It does not use this data for advertising, profiling, or any purpose unrelated to those tasks, and it does not sell data.

Where it is processed and stored

Access runs on the owner’s own computer and, for a read-only daily summary, in a private cloud environment controlled by the owner. Message content is read to perform the requested task and is processed by the AI assistant the owner uses (Claude). Sign-in tokens are kept in private files or private environment settings that only the owner can reach. Some summaries are saved as files on the owner’s computer.

Sharing

Data is not shared with anyone else, apart from the AI service the owner uses to process his own requests, and is never sold or disclosed to third parties.

Google API Services User Data Policy

Claude Gmail’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and revoking access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the stored sign-in tokens also ends access immediately.

Changes

If this policy changes, the updated version will be posted here with a new date.
